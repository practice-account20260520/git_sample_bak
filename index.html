## ディレクトリ内のファイルをステージングにアップする git add . ※ファイル名でも可能 ## ローカルとステージングの差分を確認 git status ## ローカルの変更をステージングにアップする git commit ## ステージングをリモートにアップする git push -u origin main ## コマンドにエイリアスつけました git config --global alias.com commit git config --global alias.st status git config --global alias.br branch git config --global alias.co checkout ## ignoreファイル作成 管理しないものを記載する ## 空ファイルの作成 touch xxxx.txt ▼「git diff」「git diff HEAD」「git diff --staged」の違いについて 1. git diff 未ステージの変更だけを表示 作業ディレクトリで編集したが、まだステージに追加していない内容の差分を確認します。 つまり、コミットに含まれる前の変更部分だけを見たいときに使います。 →git add 前 2. git diff HEAD 作業ディレクトリの変更と最新のコミット（HEAD）の差分を表示 未ステージの変更と、既にステージに追加された変更の両方を合わせて、最新のコミットとの差分を確認できます。 作業中のすべての変更内容を把握したいときに便利です。 →git commit 前 3. git diff --staged（または --cached） ステージに追加された変更と直前のコミットとの差分を表示 すなわち、「次のコミットに含める予定の変更内容」を確認できます。 既にステージに登録された変更内容を確認したい場合に使います。 →git push 前
